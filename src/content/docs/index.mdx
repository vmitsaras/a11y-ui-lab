## Small plugins for specific accessibility problems

The library is a collection of focused JavaScript packages—not one large framework.

Each plugin handles a defined interface problem such as presenting form errors, protecting unsaved input, managing asynchronous feedback, or coordinating keyboard interaction. Packages can be installed independently and added to existing HTML through progressive enhancement.

## Designed for progressive enhancement

Start with usable HTML. Add a plugin where native behavior or static markup is not enough.

The packages use standard DOM APIs and remain independent of React, Vue, Svelte, Astro, or another application framework. This makes them suitable for existing websites, server-rendered applications, static sites, and framework projects that need a small behavior layer.

## What you will find in each plugin guide

Every documented plugin follows a consistent structure:

- installation and package imports;
- expected semantic HTML;
- configuration options and instance methods;
- keyboard and focus behavior;
- emitted events and available addons;
- CSS customization;
- progressive-enhancement guidance;
- known constraints and accessibility considerations;
- working examples using the published npm package.

## Start with the problem you need to solve

Browse the catalog by interface problem rather than by framework.

You will find focused packages for:

- form validation and error recovery;
- loading, saving, and asynchronous feedback;
- navigation and disclosure patterns;
- dialogs, tooltips, and overlays;
- search, filtering, sorting, and result displays;
- session, network, and page-state utilities.
